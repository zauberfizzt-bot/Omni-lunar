# OMNI Lunar — servidor autónomo de notificaciones

El Blueprint render.yaml prepara un servicio permanente con disco privado (plan de pago; requiere aprobación del propietario). El servidor genera sus claves VAPID en /data, almacena las suscripciones en privado y ejecuta el motor original de resonancias y fases cada minuto. No requiere copiar claves de GitHub ni crear usuarios manualmente.

Desplegar con el Blueprint de Render o con Docker (contexto raíz y backend/Dockerfile, volumen privado /data, HTTPS). Tras comprobar GET /health y /config, publicar la URL HTTPS confirmada en push-config.json. No publicar /data ni claves privadas. El cliente migra suscripciones antiguas al nuevo servidor. Probar registro, recepción con la PWA cerrada, persistencia al reiniciar, desactivación y horarios antes de anunciar disponibilidad. La programación no garantiza puntualidad ni entrega del sistema operativo. GitHub sigue generando el banco de resonancias; el servidor usa ese banco si está fresco y conserva los mensajes locales como respaldo.
