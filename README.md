# OMNI Lunar · PWA

Aplicación: https://zauberfizzt-bot.github.io/Omni-lunar/

## Backend gratuito de notificaciones

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/zauberfizzt-bot/Omni-lunar)

El Worker usa Durable Objects SQLite y alarmas programadas por dispositivo. Ver [instrucciones del backend](cloudflare/README.md). Mantener Workers Free, sin contratar servicios de pago. Tras desplegar, verificar la URL y conectarla al sitio original. No publicar suscripciones ni claves privadas.

El backend Render queda como alternativa no activada. GitHub Pages publica la PWA y GitHub Actions genera el banco de resonancias. La entrega efectiva depende de la red y el sistema operativo.
